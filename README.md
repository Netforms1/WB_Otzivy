# WB Отзывы — Telegram-бот автоответчика на Gemini

Telegram-бот для автоматических ответов на отзывы Wildberries с помощью Google Gemini.
Управление полностью через инлайн-кнопки: выбор тона, стиля, подписи магазина, ручной просмотр и автоматический режим по расписанию.

## Возможности

- 🤖 Генерация ответов через Gemini (модель настраивается)
- 🎭 5 тонов: дружелюбный, формальный, нейтральный, извиняющийся, с юмором
- 🪶 4 стиля: коротко, средне, развёрнуто, с эмодзи
- 🔍 Фильтр по рейтингу: все / только негативные / только позитивные
- ✍️ Своя подпись магазина в конце ответа
- 📋 Ручной режим: смотришь отзыв + ответ → отправить / перегенерировать / пропустить
- 🟢 Авто-режим: бот сам забирает неотвеченные отзывы и отправляет ответы по расписанию
- 🔒 Доступ только для админов (по `ADMIN_IDS`)
- 💾 Настройки и история отправленных ответов в SQLite

## Установка

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполнить .env (см. ниже)
python -m wb_bot.bot
```

## Переменные окружения (`.env`)

| Ключ | Описание |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather) |
| `GEMINI_API_KEY` | Ключ Gemini — [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |
| `GEMINI_MODEL` | По умолчанию `gemini-2.5-flash` |
| `ADMIN_IDS` | Telegram user_id через запятую — кому разрешено пользоваться ботом |
| `AUTO_INTERVAL_MIN` | Интервал авто-цикла в минутах (по умолчанию 30) |
| `BATCH_SIZE` | Сколько отзывов забирать за раз (по умолчанию 20) |
| `DB_PATH` | Путь к SQLite (по умолчанию `bot.db`) |

## WB API-токен

В личном кабинете продавца Wildberries: **Настройки → Доступ к API → Создать токен**.
Категория — **«Отзывы и вопросы»**.

Токен пересылается боту через кнопку «🔑 Задать WB-токен». Сообщение с токеном бот сразу удаляет из чата.

## Использование

1. `/start` — главное меню.
2. Зайти в **🔑 Задать WB-токен**, отправить токен.
3. Настроить **тон**, **стиль**, **подпись**, **фильтр**.
4. Либо нажать **📋 Показать новые отзывы** для ручной работы, либо включить **🟢 Автоответ**.

## Структура

```
wb_bot/
  bot.py        — точка входа
  config.py     — настройки из .env
  db.py         — SQLite (пользователи + история)
  wb_api.py     — клиент Wildberries Feedbacks API
  gemini.py     — клиент Gemini + промпт
  keyboards.py  — инлайн-клавиатуры
  handlers.py   — все aiogram-хендлеры
  scheduler.py  — APScheduler для авто-режима
```

## Замечания

- Авто-режим работает только пока процесс бота запущен. Для постоянной работы — деплой в systemd / Docker / VPS.
- Таблица `answered` нужна, чтобы авто-режим не отвечал дважды на один и тот же отзыв.
- Все настройки персональные: у каждого админа свой токен, тон, стиль и т.д.
